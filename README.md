# DSA-project-
Introduction
The Online Shopping Cart System is a simple C programming project. It allows users to view available products, select products, enter quantities, add products to the shopping cart, view the total amount, and checkout.
2. Objective
The main objective of this project is to understand the practical use of:
Arrays
Loops
switch statement
Functions
Variables and data types
User input/output
Basic billing calculations
3. Algorithm
Start the program.
Store product names and prices.
Display the main menu.
Ask the user to select an option.
Display available products.
Ask the user to select a product and quantity.
Add the selected product to the cart.
Calculate Price × Quantity.
Display all cart items.
Calculate the grand total.
Allow the user to checkout.
Display the final bill.
Stop.
